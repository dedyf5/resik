# Core Philosophy

Resik is built on strict but minimal rules.

## Principles

1. Minimal abstraction, explicit boundaries
2. One business logic, multiple transports
3. Every module must be self-contained
4. Business logic lives in core only
5. Shared code must have clear ownership
6. Avoid unnecessary fragmentation

## Key Idea

Resik favors **clarity over abstraction**.

Abstraction is only introduced when it has clear value.
